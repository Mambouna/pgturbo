.. _examples_overview:

Example game overview
=====================

Pygame Turbo has a collection of example games which you can use to learn by
reading or modifying the code of the game. You can also play with them!

On this page, there is a picture and a link to download the example game as
a compressed ``.zip`` file as well as a link to an explainer page that talks
about how the game is written and some of the choices made for its design.

To try one of these games or look at the source code, dowload the project
``.zip`` file and extract the game folder inside. Usually, you can do this by
right-clicking on the file in your OS file explorer and choosing an option
like "extract".

Once that's done, you have a normal PGTurbo project folder and can run it like
any other.

Reading and editing source code from projects you don't know yet is a great way
to learn to code, so start hacking the code!

It's recommended that before you read through the explainer for a project, you
try to look at the source code yourself and see what you can understand already
without explanation and what you can make assumptions about to see whether you
were right.

Pygame Zero examples
--------------------

The examples above were all rewritten from the ground up with PGTurbo features
and learners looking through the code in mind. That is also why they all have
such detailed explanations.

Before these rewrites, the original Pygame Zero project had these and a number
of other example projects using different strategies and organizations for
their code and making use of different features both from PGZero and base
Pygame.

The examples that have not been ported to PGTurbo are listed below, but they do
not feature full explanations and their code might be difficult for beginners
to understand.
